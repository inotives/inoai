# Drive Claude through the installed headless CLI, not the Agent SDK

The Claude adapter spawns the owner's installed `claude -p --output-format stream-json`, resuming the stored Agent Session by ID for each Turn, rather than embedding `@anthropic-ai/claude-agent-sdk`. The SDK would give typed streaming and an in-process `canUseTool` hook, but its documentation states that third-party developers may not offer claude.ai login or rate limits for SDK-built agents unless approved, and that SDK use falls under the Commercial Terms. Running the owner's own logged-in CLI headlessly keeps inoai on the owner's subscription in the CLI's documented scripting mode, mirrors how the Codex adapter drives the local `codex` CLI, and adds no npm dependency. The cost is that inoai parses the stream-json events and treats permission denials reported by the CLI as the ADR 0007 fail-closed path; if the CLI cannot report them reliably, revisit with the owner before adding an MCP permission-prompt server.
