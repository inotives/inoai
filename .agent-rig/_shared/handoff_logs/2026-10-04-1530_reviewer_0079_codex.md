## Findings

1. **Runtime role is not required or verified.**
   `src/test/postgres.integration.test.ts` sets
   `runtimeUrl = POSTGRES_INTEGRATION_RUNTIME_URL || adminUrl`. If the runtime
   URL is omitted, all runtime operations run with the migration/admin role.
   The test then only checks schema USAGE, so it does not prove the restricted
   `inoai_sync` role has the required DML grants or lacks DDL privileges. The
   documented command provides both URLs, but the test should fail clearly when
   the runtime URL is missing (or explicitly add a separate admin-only mode).
   Add assertions for the intended runtime role and DML/DDL boundary without
   exposing connection details.

2. **Shutdown acceptance is incomplete.**
   The test exercises `PostgresOperationalStore.close()` indirectly in its
   cleanup, but it does not verify the application startup/shutdown path settles
   the lease, closes the store/pool, and leaves no active ownership. Add a
   focused shutdown assertion (for example, release/close and query the control
   lease with the admin pool) or clearly narrow the task/documentation if full
   application shutdown is intentionally deferred.
