# Task 0019 worker handoff

Added `classifyIncomingMessage` in `src/inbound-policy.ts` and exported it from the core entry point. It resolves an active, undeleted User by transport, guild, and Discord author ID. Top-level messages require the configured channel and exactly one bot mention matching this instance's bot ID. Thread messages require the configured parent channel and an active, undeleted Session bound to that thread. Bot authors, wrong locations, unknown/disabled users, unmentioned or multi-bot top-level messages, and unbound threads return `null`. This is a read-only decision; tasks 0020 and 0021 will create/archive after classification.
