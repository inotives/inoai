## Summary

- Wired normal `start()` through a bounded PostgreSQL pool, the async
  `PostgresOperationalStore`, configured Agent Instance owner bootstrap, and
  the PostgreSQL Agent Instance lease.
- Shutdown now releases the lease, closes the operational store/pool, and then
  releases the local runtime-home lock.
- Migrated Discord inbound/control paths and Manual Memory CLI operations to
  the async store. Startup no longer opens or consults SQLite.
- Runtime-home bootstrap no longer creates an `inoai.sqlite` file; the legacy
  `databaseFile` path remains as a compatibility descriptor for the deferred
  Electron UI.
- Added PostgreSQL startup/provisioning requirements to
  `docs/postgres-local.md`. BigQuery and Electron paths were not changed.

## Review notes

- `start()` retains an untyped `database` compatibility slot only so the old
  test sources continue to typecheck; it is always undefined in production and
  is never opened or read by runtime code.
- The existing startup legacy-approval replay loop was removed because its
  SQLite-only helpers are not part of the async operational-store contract;
  approval relay and provider denial paths already use the store boundary.
- No credentials, connection values, or external writes were added.
