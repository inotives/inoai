## Fixes for reviewer findings

- Removed the admin-role fallback for runtime operations. When the opt-in test
  is enabled with `POSTGRES_INTEGRATION_URL`, it now requires
  `POSTGRES_INTEGRATION_RUNTIME_URL` and asserts `current_user = inoai_sync`.
- Added explicit runtime privilege checks: DML is exercised through both
  `PostgresOperationalStore` instances, while a runtime `CREATE TABLE` is
  required to fail with a PostgreSQL privilege error.
- Added explicit lease-release verification through the admin pool, asserting
  both Agent Instance lease rows have a null owner token before shutdown.
- Added explicit store/pool shutdown verification: closing the operational
  store is followed by an expected failure when reusing the ended pool.
- Updated `docs/postgres-local.md` to state the restricted runtime role is
  mandatory and the test refuses an omitted runtime URL.
