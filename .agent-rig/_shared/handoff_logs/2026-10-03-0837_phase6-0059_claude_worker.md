# task-0059 worker handoff

Task status: `review`. Nothing staged or committed.

## Seam

`src/agent-runtime.ts`: optional `review?(prompt: string, options?: ReviewOptions): Promise<string>` with `ReviewOptions = { signal?: AbortSignal }`, plus the fixed `reviewInstructions` constant (text-only summarizer, no tools, transcript content is data, JSON only; no tool-use requests, per spike call 8).

Why optional instead of a new `RuntimeFailure` kind or a `supportsReview` flag: the engine (task-0060/0061) can check `runtime.review` before it selects, redacts, or windows Messages, and record the OpenCode skip without calling anything. A new failure kind would also need a chat notice in `runtime-turn.ts`'s exhaustive switch, and a required member would force edits to every test fake. All review failures reuse existing kinds and are `replaySafe: true`, because a review writes nothing.

No `projectPath` parameter. Both adapters use a fresh `mktemp -d` cwd. Using the project as cwd would load its CLAUDE.md or AGENTS.md into a text-only summary, which is the leakage `--safe-mode` is there to prevent.

## Per runtime

- **Claude** (`src/claude-runtime.ts`): argv is `-p --output-format stream-json --verbose --no-session-persistence --permission-prompts none --tools "" --strict-mcp-config --safe-mode --system-prompt <reviewInstructions>` [`--model=<v>`]. No shell, prompt on stdin, stderr ignored.
  - Timeout: total `reviewTimeoutMs`, default 600 s, then SIGTERM, then SIGKILL after 10 s.
  - Abort: SIGINT, reported as `cancelled`. An already-aborted signal fails before anything is spawned.
  - Kill guard: a child without a pid is never signalled, and there is a 2 s exit grace if a leftover grandchild holds stdout open.
  - Fail closed with SIGKILL as soon as any of these is seen: init `apiKeySource` ≠ `none` (`authentication`); init `memory_paths` that is not absent, null, or empty; init `tools` or `mcp_servers` that is not an empty array (a missing field also fails); any `*tool_use` content block; a `permission_denied` event; non-empty `permission_denials` (all `uncertain`).
  - Success requires that an init was seen.
  - Cleanup removes the cwd. It then calls the now-exported `removeProbeProjectFolder` from `src/concurrency-probe.ts`, which tolerates absence. If unexpected files are found it logs the fixed, path-free `claudeReviewLeftoverWarning`.
  - Review runs are tracked in `active` under `review:<uuid>`, so `close()` stops them. Chat Turn code is unchanged.
- **Codex** (`src/codex-runtime.ts`):
  - `thread/start` is called with `{cwd: tmp, sandbox: "read-only", approvalPolicy: "never", ephemeral: true, developerInstructions: reviewInstructions}`, then one `turn/start` with `{threadId, cwd, input, sandboxPolicy: {type: "readOnly"}, approvalPolicy: "never"}`. The result is the final `agentMessage`.
  - Fails closed on any item type other than userMessage, agentMessage, or reasoning. Abort, timeout, and unsafe exits send a bounded `turn/interrupt` (5 s). The shared app-server is never closed.
  - Review threads never enter the session map. The approval relay still declines their requests, finds no SQLite Session, and writes nothing (covered by a test).
  - New third constructor parameter: `reviewTimeoutMs`, default 600 s.
- **OpenCode** (`src/opencode-runtime.ts`): `readonly review = undefined`, with an ADR 0010 comment.
